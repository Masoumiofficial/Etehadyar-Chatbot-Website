راه‌اندازی پنل همین وب‌سایت

این بسته سایت معرفی محصول است، نه خود افزونه وردپرس. برای استفاده از CMS، هاست PHP نیاز است.

  1. فایل‌های سایت و تنظیمات محافظت وب‌سرور را در روت عمومی قرار دهید.
  2. در ترمینال هاست فرمان php scripts/setup-admin.php --username YOUR_USERNAME را اجرا کنید. رمز پیش‌فرض وجود ندارد و رمز انتخابی فقط به‌صورت هش خارج از پوشه عمومی ذخیره می‌شود.
  3. از صفحه پنل مدیریت وارد شوید و لینک‌های واقعی HTTPS درگاه پرداخت را ثبت کنید. تا آن زمان خرید غیرفعال است.
  4. بعد از ذخیره موفق، صفحات عمومی اطلاعات data/site_data.json را می‌خوانند. فایل ZIP پنل فقط شامل داده‌های ذخیره‌شده و فایل‌های عمومی است، نه رمز یا نشست‌ها.

مستندات بعدی امکانات افزونه را توصیف می‌کنند؛ این سایت مدل AI یا صف وردپرس را اجرا یا پایش نمی‌کند.

۱. نیازمندی‌ها و نصب سریع در وردپرس

اتحادیار به صورت یک افزونه کاملاً استاندارد و سبک برای وردپرس طراحی شده است و به هیچ کتابخانه خارجی (مانند Composer) یا سرورهای واسط سنگین وابسته نیست.

حداقل نیازمندی‌های هاست و سرور:
  • نگارش وردپرس: WordPress 6.0 به بالا
  • نگارش پی‌اچ‌پی: PHP 7.4 تا PHP 8.3+ (سازگار با هاست‌های اشتراکی سی‌پنل و دایرکت‌ادمین)
  • ماژول‌های فعال PHP: curl, openssl, json, mbstring
  • افزونه اختیاری: FFmpeg روی سرور برای رندر مستقیم فایل‌های ویدیویی MP4 (در صورت عدم وجود، پیش‌نمایش HTML و فایل SRT ارائه می‌شود).

۲. صندوق امنیتی کلیدها (EAIW_Vault)

اتحادیار از صندوق رمزنگاری‌شده داخلی بر پایه الگوریتم پیشرفته AES-256-GCM استفاده می‌کند. کلیدهای API سرویس‌های OpenAI, Gemini, Claude و GapGPT با استفاده از سالت‌های اختصاصی فایل wp-config.php شما رمزگذاری می‌شوند.

  • کلیدها هرگز در سورس‌کد مرورگر یا فرانت‌اند سایت افشا نمی‌شوند.
  • درخواست‌ها مستقیماً از سمت سرور شما (Server-to-Server) به API ارائه‌دهنده ارسال می‌شوند.
  • امکان تعریف چندین پروفایل کلید و سوییچ خودکار در صورت اتمام اعتبار وجود دارد.

۳. دستیار صوتی زنده و تبدیل گفتار Whisper

در نگارش ۶.۱۲، قابلیت گفت‌وگوی صوتی پیوسته فارسی به هسته محصول اضافه شد. این ماژول بر پایه دو ستون عمل می‌کند:

  1. تشخیص گفتار پیوسته (Live Speech Mode): استفاده از Web Speech API برای شنیدن گفتار فارسی، تشخیص هوشمند مکث‌های کاربر و پخش صوت پاسخ با speechSynthesis.
  2. درخواست‌های صوتی طولانی (Whisper STT): ضبط صدا با فرمت‌های WebM/MP3/OGG تا سقف ۸ مگابایت با MediaRecorder و تبدیل دقیق به متن فارسی توسط مدل Whisper، الصاق فایل صوتی به تیکت کارشناس و پاک‌سازی خودکار پس از ۷ روز.

۴. کارخانه محتوای چندکاناله (Omnichannel Content Factory)

کارخانه محتوا با دریافت یک پرامپت یا موضوع، همزمان هفت خروجی استاندارد تولید می‌کند:

  • مقاله HTML سئو شده: همراه با کیفیت‌سنج Quality Gate، ساختار هدینگ، جدول و اسکیمای FAQ.
  • تصاویر Flux: تولید تصاویر با هوش مصنوعی و ثبت مستقیم در Media Library با تگ Alt فارسی.
  • سناریوی ویدیویی و SRT: تفکیک صحنه‌ها، متن روخوانی و فایل زیرنویس همگام SRT.
  • پادکست و صوت: سنتز گفتار روان فارسی با قابلیت دانلود فایل MP3.
  • کاروسل و شبکه‌های اجتماعی: کپی آماده برای اینستاگرام، تلگرام و توییتر.
  • ایمیل مارکتینگ: عنوان با نرخ بازگشایی بالا و بدنه ترغیب‌کننده.

۵. صف کارهای نامتقارن (Background Job Queue)

برای جلوگیری از خطای Maximum Execution Time در هاست‌های اشتراکی، تمامی عملیات حجیم در جدول اختصاصی صف ذخیره شده و توسط کران‌جاب ۱۵ دقیقه‌ای وردپرس پردازش می‌شوند. در صورت قطعی اینترنت یا خطای موقت API، سیستم تلاش مجدد (Smart Exponential Retry) کار را به پایان می‌رساند.

۶. فروش‌یار ووکامرس (WooCommerce Turbo)

اتصال مستقیم به جداول کاتالوگ ووکامرس برای بازنویسی و غنی‌سازی دسته‌ای محصولات ضعیف، ایجاد جدول مشخصات فنی، تولید پرسش‌های متداول خریداران و افزایش نرخ تبدیل فروشگاه.

۷. عیب‌یابی و پرسش‌های رایج فنی
